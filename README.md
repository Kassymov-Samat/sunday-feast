# 🪷 Воскресный пир — меню и закуп

Сайт для повара и закупщика: https://kassymov-samat.github.io/sunday-feast/

1. **Повар** отмечает блюда в справочнике и указывает число гостей — список закупа считается сам
   по раскладке прошлых мероприятий (количество на одного гостя × гости). До 250 гостей продукты на блюда
   берутся с запасом (до +30% при 40 гостях): по меню 2023–2026 на маленьких мероприятиях на человека уходит больше.
2. Список разбит на разделы: Молочка · Бакалея · Овощи и фрукты · Специи · Остальное · Хоз. часть.
   Любое количество можно исправить, позицию — убрать галочкой или добавить из справочника / свою.
3. **Закупщик** правит цены прямо в списке. Цены с пометкой «среднее» — средние по старым закупам, их стоит уточнить.
4. Кнопка **«Открыть в Google Таблицах»** создаёт онлайн-таблицу (доступ по ссылке), **«Скачать Excel»** — файл; листы:
   Сводка · Молочка · Бакалея (+ специи) · Овощи и фрукты · Остальное (+ хоз. часть); суммы — формулами.

Правки и выбор сохраняются в браузере (у каждого — свои).

## Откуда данные

- **Блюда** — «20260502_Меню на Майский ретрит.xlsx» и все меню/закупы за 2023–2026 из папки `C:\projects\блюда`
  (130 блюд без повторов). Одно блюдо, записанное по-разному («Дымляма»/«дамляма», «Гулабы»/«Гулабджамуны»,
  «Напиток» с лимоном/каркаде/шиповником), собирается в одно. Количество продукта на гостя — медиана по всем
  приготовлениям, где он есть в большинстве; состав блюд ретрита — как был. Гхи делаем сами — везде сливочное масло.
- **Цены** — с майского ретрита; если продукта там нет — среднее по всем файлам (по каждому файлу своё среднее,
  выбросы больше чем в 2 раза от медианы отброшены). Сливочное масло — 3 500 ₸/кг.
- **Специи** — норма упаковок на 100 гостей по итогам закупа ретрита, минимум 1 упаковка.
- Блюда, уже добавленные на сайте вручную (Шак панир, Чола, облепиховый напиток), из файлов не дублируются.

## Файлы

- `index.html` — сайт
- `data/dishes.js` — справочник блюд (на одного гостя), `data/catalog.js` — продукты, специи, хоз. часть, цены
- `data/config.js` — адрес скрипта Google (справочник и экспорт)
- `apps-script/` — скрипт Google Apps Script для экспорта в Google Docs (установка — в README там же)
- `tools/build_data.py` — пересобрать справочники: `python tools/build_data.py`
  (разбор старых меню — `tools/parse_history.py`, цены из таблиц — `tools/price_sources.py`,
  id блюд закреплены в `tools/dish_ids.json`)
