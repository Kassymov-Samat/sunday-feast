# 🪷 Воскресный пир — меню и закуп

Сайт для повара и закупщика: https://kassymov-samat.github.io/sunday-feast/ (локально — http://localhost:8794)

Пошагово:

0. **Сверху** — название, **дата пира** и **число гостей**. По дате выбирается сезон цен:
   ❄️ зима–весна (дек–май) · ☀️ лето (июн–авг) · 🍂 осень (сен–ноя); кнопкой сезона можно выбрать вручную.
1. **Меню** — цветные блоки: Сабджи, Рис и плов, Супы и далы, Закуски, Сладкое, Напитки, Салаты, Выпечка, Соусы, Каши, Фрукты.
   Нажали блок — открываются карточки блюд (фото, состав, ≈ цена на гостя), нажали карточку — блюдо в меню.
   Внизу — список выбранного и сумма; «Подтвердить меню →». Поиск — клавиша `/`.
2. **Ингредиенты** — состав каждого блюда на число гостей; правки только для этого пира, ✎ — в справочнике для всех.
3. **Закуп** — список продуктов по разделам, цены сезона, Google Таблица / Excel / текст для WhatsApp.
   Листы таблицы: Сводка · Раскладка · Молочка · Бакалея (+ специи) · Овощи и фрукты · **Заморозка**
   (замороженные горошек, стручковая фасоль, ягоды) · Остальное (+ хоз. часть).
4. **Афиша** — бордо и золото, фото блюд, описания из реального состава; пост 1080×1350, сторис 1080×1920,
   A4 и A3 для печати → PNG. Правила стиля, промпты и чек-лист — `poster-guide.html`.

## Откуда данные

- **Блюда** — «20260502_Меню на Майский ретрит.xlsx», меню/закупы 2023–2026 из `C:\projects\блюда`,
  меню 2025–2026 из `пир\готовка — копия` и архив Google Drive 2011–2019 (`C:\projects\блюда\архив-drive`) —
  204 блюда без повторов. Сабджи из старых меню («Сабджи(картошка, цв капуста в сметане)») называются по овощам
  и соусу; один набор овощей в разных соусах — одно блюдо. Если в файле не указано число гостей — берётся из порций
  в меню или одноразовой посуды, иначе оценивается по раскладке. Блюда из архива с явно завышенной порцией
  приводятся к типичной для раздела (в «откуда» это написано). Одно блюдо, записанное по-разному («Дымляма»/«дамляма», «Гулабы»/«Гулабджамуны»,
  «Напиток» с лимоном/каркаде/шиповником), собирается в одно. Количество продукта на гостя — медиана по всем
  приготовлениям, где он есть в большинстве; состав блюд ретрита — как был. Гхи делаем сами — везде сливочное масло.
- **Цены 2026 по сезонам** — закупы этого сезона 2025–2026 (2025 год +10%), майский ретрит (зима–весна),
  закупы сентября–октября 2026 (осень). Где закупов сезона нет — пересчёт от известной цены по сезонному
  коэффициенту (зелень и тепличные овощи зимой дороже, летом/осенью дешевле; цитрусы — наоборот; бакалея — ровно).
  Цена, исправленная на сайте в «Продукты и цены», действует на все сезоны.
- **Базовая цена** — с майского ретрита; если продукта там нет — среднее по всем файлам (по каждому файлу своё среднее,
  выбросы больше чем в 2 раза от медианы отброшены). Сливочное масло — 3 500 ₸/кг.
- **Специи** — норма упаковок на 100 гостей по итогам закупа ретрита, минимум 1 упаковка.
- Блюда, уже добавленные на сайте вручную (Шак панир, Чола, облепиховый напиток), из файлов не дублируются.

- **Правки на сайте** (✎ у блюда, «Продукты и цены») хранятся в скрипте Google и видны всем.
  19.11.2026 все прежние правки сброшены — справочник как в исходных файлах (`SITE_EDITS_RESET` в `data/config.js`;
  копия сброшенных правок — `C:\projects\блюдаackup\`). Правки после этой даты работают как обычно.
- Цены из старых закупов пересчитаны к 2026 году по году файла: 2023 — +30%, 2024 — +20%, 2025 — +10%.

## Файлы

- `index.html` — сайт
- `data/dishes.js` — справочник блюд (на одного гостя), `data/catalog.js` — продукты, специи, хоз. часть, цены
- `data/config.js` — адрес скрипта Google (справочник и экспорт)
- `apps-script/` — скрипт Google Apps Script для экспорта в Google Docs (установка — в README там же)
- `tools/parse_more.py` — разбор меню из папки «пир» и архива Drive
- `tools/gen_images.py` — фото блюд через ChatGPT (`python tools/gen_images.py`; открывается Chrome, войти один раз;
  можно прерывать — продолжит с места; фото в `data/img/`)
- `poster-guide.html` — гайд по афише: размеры, цвета, шрифты, композиция, промпты, чек-лист
- `tools/build_data.py` — пересобрать справочники: `python tools/build_data.py`
  (разбор старых меню — `tools/parse_history.py`, цены из таблиц — `tools/price_sources.py`,
  id блюд закреплены в `tools/dish_ids.json`)
