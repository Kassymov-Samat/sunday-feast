# 🪷 Ведический воскресный пир

Вегетарианское меню в духе книги Адираджа даса «Ведическое кулинарное искусство»
(без мяса, рыбы, яиц, лука, чеснока и грибов).

Выберите блюда и число гостей — сайт соберёт список продуктов и отдельно список специй
с ценами по магазинам Алматы (arzan.kz). Любую позицию можно снять галочкой,
список покупок — скопировать, меню — отправить ссылкой.

## Файлы

- `index.html` — сайт (без сборки, открывается в любом браузере)
- `data/dishes.js` — **справочник блюд**: состав на одного гостя, продукты и специи отдельно
- `data/prices.js` — цены (генерируется скриптом)
- `tools/products.py` — справочник продуктов и правила поиска на arzan.kz
- `tools/fetch_prices.py` — обновить цены: `python tools/fetch_prices.py`

## Как добавить блюдо

Скопируйте блок в `data/dishes.js` и поменяйте состав. Ключи продуктов — как в `tools/products.py`.
Если нужен новый продукт — добавьте его в `tools/products.py` и запустите `fetch_prices.py`.
