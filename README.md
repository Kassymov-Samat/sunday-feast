# 🪷 Воскресный пир — меню и закуп

Сайт для повара и закупщика: https://kassymov-samat.github.io/sunday-feast/

1. **Повар** отмечает блюда в справочнике и указывает число гостей — список закупа считается сам
   по раскладке майского ретрита (количество на одного гостя × гости).
2. Список разбит на разделы: Молочка · Бакалея · Овощи и фрукты · Специи · Остальное · Хоз. часть.
   Любое количество можно исправить, позицию — убрать галочкой или добавить из справочника / свою.
3. **Закупщик** правит цены прямо в списке. Цены с пометкой «май» — устаревшие.
4. Кнопка **«Скачать Excel»** выгружает файл с листами
   Сводка · Молочка · Бакалея (+ специи) · Овощи и фрукты · Остальное (+ хоз. часть); суммы — формулами.

Правки и выбор сохраняются в браузере (у каждого — свои).

## Откуда данные

- **Блюда** — «20260502_Меню на Майский ретрит.xlsx»: каждое блюдо пересчитано на одного гостя
  (количество ÷ число гостей того приёма пищи). Гхи делаем сами — везде сливочное масло.
- **Цены** — по свежести: «Закуп 17.10.2026» → «Радхаштами 2026» (сентябрь) → майский ретрит.
  Сливочное масло — 3 500 ₸/кг.
- **Специи** — норма упаковок на 100 гостей по итогам закупа ретрита, минимум 1 упаковка.

## Файлы

- `index.html` — сайт
- `data/dishes.js` — справочник блюд (на одного гостя), `data/catalog.js` — продукты, специи, хоз. часть, цены
- `data/config.js` — адрес скрипта Google Docs
- `apps-script/` — скрипт Google Apps Script для экспорта в Google Docs (установка — в README там же)
- `tools/build_data.py` — пересобрать справочники: `python tools/build_data.py`
  (цены из таблиц — в `tools/price_sources.py`)
