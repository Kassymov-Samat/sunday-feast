# Экспорт списка закупа в Google Docs

Скрипт создаёт Google Doc с вкладками **Сводка · Молочка · Бакалея · Овощи и фрукты · Остальное**
(специи — во вкладке «Бакалея», хоз. часть — в «Остальное») и возвращает ссылку на документ.
Документы создаются на Google Диске того, кто установил скрипт; ссылка открывается у всех с правом редактирования.

## Установка (один раз, ~3 минуты)

1. Откройте https://script.google.com под нужным Google-аккаунтом → **Новый проект**.
2. Назовите проект «Воскресный пир — экспорт».
3. Скопируйте содержимое `Code.gs` в редактор (заменив то, что там есть).
4. ⚙ **Настройки проекта** → включите «Показывать файл манифеста appsscript.json» →
   откройте `appsscript.json` и замените содержимым одноимённого файла из этой папки.
5. **Начать развёртывание → Новое развёртывание** → тип «Веб-приложение»:
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   → «Развернуть» → разрешите доступ (Google спросит про Документы и Диск — это нужно, чтобы создавать документ).
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и вставьте на сайте:
   ⚙ «Настройки» → «Адрес скрипта Google Docs». Или пришлите его — пропишу на сайте для всех.

Необязательно: чтобы документы складывались в одну папку — «Настройки проекта» →
«Свойства скрипта» → добавить `FOLDER_ID` = id папки на Диске (из её адреса).
